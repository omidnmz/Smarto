# اسمارتو · پنل هوشمند کسب‌وکار

سامانه‌ای که هر صاحب کسب‌وکار با شماره موبایلش وارد می‌شود و برای کسب‌وکارش یک پنل مدیریت موبایلی می‌سازد: فروش، نوبت‌ها، مشتری‌ها، تیم و کارهای روزانه. ده نمونه (فروشگاه کفش، سالن زیبایی، کلینیک، فروشگاه آنلاین، کافه، رستوران، تعمیرگاه، سوپرمارکت، طلافروشی، املاک) برای تماشا آماده است. کسب‌وکارهایی که در نمونه‌ها نیستند فرم نیازسنجی پر می‌کنند و بعد از تأیید مدیر سامانه، شغل جدید و پنلشان ساخته می‌شود.

## دسترسی‌ها

- **ورود:** با کد یکبارمصرف پیامکی (۵ رقم، ۲ دقیقه اعتبار).
- **صاحب کسب‌وکار:** هر چیزی را در پنل خودش می‌بیند و تغییر می‌دهد و می‌تواند «نمایش برای» را عوض کند تا پنل را از چشم هر نقش ببیند.
- **اعضای تیم:** صاحب کسب‌وکار در «تیم و تنظیمات» شماره موبایلشان را ثبت می‌کند؛ با همان شماره وارد می‌شوند و فقط بخش‌های نقش خودشان را می‌بینند. حقوق فقط برای مالک و مدیر کل، و هزینه‌ها فقط برای مالک، مدیر کل و مدیر باز است.
- **مدیر سامانه:** شماره‌ای که در `ADMIN_PHONE` گذاشته شده. همه کسب‌وکارها و صندوق درخواست‌های شغل جدید را می‌بیند.
- **نمونه‌ها:** برای همه (حتی بدون ورود) قابل تماشا و غیرقابل تغییرند. با هر بار اجرای سرور دوباره بارگذاری می‌شوند تا تاریخ‌هایشان به‌روز بماند.

## انتشار روی لیارا

1. در پنل لیارا یک **دیتابیس PostgreSQL** بسازید (در همان شبکه برنامه) و آدرس اتصال داخلی آن را بردارید.
2. برنامه Node.js با نام `smarto1` بسازید. اگر نام دیگری گذاشته‌اید، مقدار `app` را در `liara.json` عوض کنید.
3. در بخش **تنظیمات › متغیرها** این‌ها را بگذارید:

   | متغیر | مقدار |
   | --- | --- |
   | `DATABASE_URL` | آدرس اتصال دیتابیس از مرحله ۱ |
   | `SESSION_SECRET` | یک رشته تصادفی بلند (مثلاً خروجی `openssl rand -hex 32`) |
   | `ADMIN_PHONE` | شماره موبایل خودتان، مثل `0912…` |
   | `NODE_ENV` | `production` |
   | `KAVENEGAR_API_KEY` و `KAVENEGAR_TEMPLATE` | اختیاری؛ تا وقتی تنظیم نشده‌اند کد ورود فقط در لاگ برنامه چاپ می‌شود |

4. انتشار، یکی از این دو راه:
   - **خودکار از گیت‌هاب:** در لیارا از بخش حساب کاربری یک API Token بگیرید و در گیت‌هاب در `Settings › Secrets and variables › Actions` با نام `LIARA_API_TOKEN` ذخیره کنید. از آن به بعد هر تغییری که در `main` ادغام شود خودکار منتشر می‌شود.
   - **دستی:** `npm i -g @liara/cli`، سپس `liara login` و `liara deploy` در پوشه پروژه.
5. بعد از اولین اجرا، جدول‌ها و نمونه‌ها خودکار ساخته می‌شوند. با شماره `ADMIN_PHONE` وارد شوید؛ کد ورود را (تا وقتی کاوه‌نگار وصل نیست) در **لاگ‌های** برنامه در لیارا ببینید.
6. دامنه: در بخش **دامنه‌ها** دامنه را اضافه کنید، رکورد DNS را طبق راهنمای لیارا بگذارید و SSL رایگان را فعال کنید.

### پیامک ورود با کاوه‌نگار

در پنل کاوه‌نگار یک الگوی «اعتبارسنجی» با یک توکن (`%token`) بسازید، مثلاً «کد ورود اسمارتو: %token». نام الگو را در `KAVENEGAR_TEMPLATE` و کلید API را در `KAVENEGAR_API_KEY` بگذارید.

## اجرای محلی

```bash
npm install
cp .env.example .env   # و مقدارها را پر کنید
export $(grep -v '^#' .env | xargs)
npm start              # http://localhost:3000
```

تست‌ها یک دیتابیس خالی و دورریختنی لازم دارند:

```bash
TEST_DATABASE_URL=postgres://localhost/smarto_test npm test
```

## ساختار

- `server/`: سرور Fastify. `access.js` قواعد دسترسی، `store.js` ذخیره اسناد در PostgreSQL، `auth.js` ورود پیامکی، `seed.js` نمونه‌ها.
- `public/`: خود پنل (HTML/CSS/JS بدون فریم‌ورک). `api.js` لایه ارتباط با سرور و به‌روزرسانی زنده است.
- `seed/samples.json`: داده نمونه‌ها.

محدودیت فعلی: به‌روزرسانی زنده بین کاربران از حافظه همان سرور می‌گذرد، پس برنامه باید روی **یک نمونه** (instance) اجرا شود که پیش‌فرض لیاراست.
